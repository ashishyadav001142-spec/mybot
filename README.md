# 🤖 Prime Doraemon Telegram Bot (Python)

High-performance, single-file Telegram bot powered by `pyTelegramBotAPI`.

## 🚀 Features
- **Ultra-Fast (< 0.05s)** response via continuous Long Polling
- **Persistent SQLite Database** (`bot_database.db`)
- **Stylish Small-Caps Typography** across all text & buttons
- **2 Buttons Per Line** layout outside chat
- **Smart No-Data Fallback**: `⚠️ ɴᴏ ᴅᴀᴛᴀ ᴀᴠᴀɪʟᴀʙʟᴇ ᴄᴜʀʀᴇɴᴛʟʏ`
- **Full Owner Admin Panel**: Add Buttons, Add Apps, Add Files, Channel Verification

## 📦 Run Locally
```bash
pip install -r requirements.txt
python bot.py
```

## 🌐 Deploy to Render / Cloud
- Build Command: `pip install -r requirements.txt`
- Start Command: `python bot.py`
